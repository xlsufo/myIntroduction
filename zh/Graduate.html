# 项目职责

  • 负责验证机总体方案设计，涵盖倾转旋翼建模、桨叶设计、气动外形设计、结构强度校核及动力系统设计；
  • 主导关键部件试验方案制定，协调团队完成风洞试验与结构载荷测试，基于试验数据优化设计，提升系统的环境适应性与安全性；；
  • 参与项目论证，编写技术可行性报告及成本分析，推动项目从研发向量产转化，已交付用于低空侦察与物资运输场景测试。

# 项目成果

  • 完成无人倾转旋翼验证机总体设计，通过试验验证其最大起飞重量达 25 kg，倾转过渡阶段稳定性满足设计要求；
  • 项目成功转化为正式产品，已实现小批量生产，交付用于低空侦察与物资运输场景测试。

# Matlab与FlightGear联合的制导弹药可视化仿真

# 项目描述

为实现无人机飞行状态的可视化验证，开发基于 FlightGear 的视景仿真系统。该系统旨在通过实时接收无人机位姿数据，将 Matlab 仿真结果及嵌入式仿真板的运行状态以三维视景形式重现，为无人机控制算法调试与飞行状态分析提供直观支撑。

# 项目职责

  • 搭建无人机视景仿真环境，结合物理参数与三维模型，实现对无人机飞行动态的真实感知与反馈；
  • 在嵌入式仿真板上运行倾转旋翼动力学模型，支持控制信号的实时输入与动力学响应输出，构建闭环仿真控制系统；
  • 开发基于 UDP 的数据接收模块，实现多平台间位姿信息的实时同步；

# 项目成果

  • 成功构建视景仿真系统，UDP 数据接收延迟控制在 50ms 以内；
  • 系统支持多场景切换与飞行参数实时标注，为控制算法的调试效率提升，减少了实地测试前的算法迭代周期。
