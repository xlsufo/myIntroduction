# 车顶起降Fluent分析

# 项目描述

  • 为解决无人机在车顶动态起降时受气流扰动导致的稳定性问题，开展基于 Fluent 的气动分析与结构优化项目。通过研究车顶地效、自然风等因素对无人机的气流干扰规律，设计针对性机械结构，实现安全高效的车顶动态起降。

# 项目职责

  • 负责建立车顶 - 无人机流场模型，基于 Fluent 进行数值仿真，分析不同风速（0-30m/s）、起降高度下的气流压力分布与湍流强度；
  • 提取无人机受扰力与力矩数据，制定机械结构优化方案（如加装导流板、调整起落架布局），削弱气流扰动影响；
  • 参与动态起降试验，对比仿真结果与实测数据，迭代优化结构设计。

# 项目成果

  • 通过 Fluent 仿真明确气流扰动规律，优化后的机械结构使无人机起降时的侧向力波动降低 40%；
  • 成功实现车顶动态起降（车速 0 - 50km/h），起降成功率提升至 90%，满足实际应用需求。

# 共轴垂直起降无人机设计

# 项目描述

针对共轴双旋翼布局的垂直起降无人机开展总体结构设计，旨在通过优化结构布局与重量分配，提升无人机的升力效率与飞行稳定性。

# 项目职责

  • 担任项目负责人，带领 3 人团队完成总体结构设计，包括旋翼系统布局、机身框架选型、动力装置安装方案设计等；
  • 主导结构强度仿真分析（使用 ANSYS），针对关键承重部件进行应力校核与优化，降低结构重量 15%；

# 项目成果

  • 完成共轴垂直起降无人机总体结构设计，整机重量控制在 5 kg 以内，最大有效载荷提升 20%；
  • 经试飞验证，无人机悬停精度达 ±0.2m，续航时间延长至 20 分钟，满足设计指标。

# 语音控制四轴

# 项目描述

为拓展四轴无人机的操控方式，开发支持语音控制的系统。通过在 Ubuntu16.0 环境下二次开发开源飞控与地面站，结合语音识别技术，实现无人机的语音指令响应与远程操控。

# 项目职责

  • 在 Ubuntu16.0 系统中搭建基于 Qt 的开发环境，配置 px4 开源飞控代码及 QGC 地面站的编译工具链，完成环境调试与版本适配；
  • 对 px4 飞控进行二次开发，新增语音指令解析接口，实现 “起飞”“悬停”“返航” 等指令的控制逻辑；
  • 开发语音识别 APP（基于 Android 平台），通过蓝牙与地面站通信，支持语音指令与传统遥控器的双模控制。

# 项目成果

  • 成功搭建开发环境，二次开发后支持语音指令的响应延迟≤1s；
  • 语音识别 APP 指令识别准确，实现无人机语音控制与遥控器控制的无缝切换。
